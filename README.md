## 2. AI Solution Worksheet
This project looks at a real business problem. Organizations struggle to set fair, competitive salaries for data science roles. Compensation varies by experience level, job title, employment type, remote ratio, and location. Without good benchmarking data, companies risk overpaying or losing talent to underpaying. Using historical salary data, I designed a supervised learning (regression) solution to predict what a full-time, entry-level data scientist should be paid in USD, based on features like work year, experience level, employment type, job title, remote ratio, company location, and company size.
